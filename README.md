# pokemon_calc

## Journal des décisions de l'IA

À chaque décision, l'IA ajoute son analyse minimax au fichier
`calculatrice_pokemon/IA/ai_decisions.log` : les scores des actions adverses
simulées, l'action du joueur prédite comme optimale et le choix finalement
retenu. Il est vidé au début de chaque nouveau combat, puis complété à chaque
décision.
